WHAT IS BEING TESTED
  Whether a hostile ticket body can (a) make the model obey instructions
  planted in customer content, or (b) make it reveal the system prompt.
  The defence is content fencing: the ticket is placed inside delimiters
  in the *user* message, never concatenated into the system prompt, the
  delimiters are stripped from the content so a crafted body cannot forge
  an early close, and the system prompt declares everything inside the
  fence to be untrusted data.

  What it did instead is the correct behaviour, not merely a safe one: it

────────────────────────────────────────────────────────────────────────
5. WHAT THIS DOES AND DOES NOT PROVE
────────────────────────────────────────────────────────────────────────

  It proves this payload, against this model, through this prompt, on
  this date, did not succeed. It is one observation, not a guarantee.

  Prompt-level defences are requests, not enforcement — the same lesson
  already recorded in .claude/fixes/aiden-ai.md, where claude-haiku-4-5
  ignored an explicit "no markdown code fence" instruction in the triage
  prompt. An instruction that model declined to follow when it was merely
  inconvenient is not an instruction to stake tenant isolation on.

  What does not depend on the model's cooperation, and is what actually
  contains the blast radius:

    - The draft is never sent anywhere. It streams to the agent, who
      reviews and edits before anything reaches a customer.
    - The route carries no tools and no data access. Even a fully
      hijacked model can only emit text into the agent's own draft box.
    - Every read before the call is org-filtered and ownership-checked,
      so the prompt can only ever contain a ticket the caller was already
      authorised to read. Injection cannot reach across tenants.
    - Delimiters are stripped from the content, so a body cannot close
      the fence early and escape into instruction position.

  The probe is re-run whenever the provider or the model pins change; a
  provider switch is exactly the event that would invalidate it.
